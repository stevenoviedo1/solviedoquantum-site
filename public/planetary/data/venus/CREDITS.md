# Venus data credits

Surface topography is a **hybrid model** informed by published Magellan radar altimetry / feature locations (Maxwell Montes, Aphrodite Terra, Beta Regio, Ishtar Terra, Maat Mons).

Not a distributed Magellan DEM product. For research: NASA PDS Magellan GTDR / SAR mosaics.

Atmosphere presentation is artistic (opaque cloud deck + thick CO₂ haze).
